# 💰 ФинТрекер — Личный финансовый трекер

Полноценное PWA-приложение для управления личными финансами с поддержкой бюджетов, долгов, аналитики и импорта из Excel.

## 🚀 Возможности

### Основной функционал
- **Дашборд** — общая картина финансов с одного взгляда
- **Операции** — доходы, расходы, переводы, платежи по долгам
- **Счета** — дебетовые карты, кредитки, наличные, вклады, кошельки
- **Бюджеты** — лимиты по категориям с прогнозом превышения
- **Долги** — кредиты, кредитные карты, личные долги с симулятором погашения
- **Аналитика** — графики по категориям, акторам, месяцам, неделям
- **Цели** — накопления с прогрессом и дедлайнами
- **Подписки** — учёт регулярных платежей

### Финансовая логика
- Переводы между своими счетами НЕ считаются расходами
- Оплата тела кредита НЕ считается обычным расходом
- Проценты и комиссии учитываются как финансовые расходы
- Амортизация крупных трат (годовые подписки = 1/12 в месяц)
- Расчёт свободных денег, обязательной и кредитной нагрузки
- Чистая стоимость = активы − обязательства

### Импорт и экспорт
- Импорт из Excel (.xlsx) с авто-нормализацией категорий
- Экспорт в Excel, CSV и полный JSON-бэкап
- Автоматическое создание категорий и акторов при импорте
- Определение операций, требующих проверки

### PWA
- Установка на смартфон как приложение
- Работа офлайн (данные в localStorage)
- Мобильный-first интерфейс
- Нижняя навигация для смартфона
- Тёмная и светлая тема

## 📱 Установка PWA

### На iPhone (Safari)

2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)

3. Или дождитесь баннера "Установить приложение"

## 📊 Модель данных

### Сущности
- **Account** — счёт (карта, наличные, вклад, кредитка, кошелёк)
- **Actor** — человек или организация (Мама, Stentran, Ozon)
- **Category** — категория расходов (древовидная структура)
- **Tag** — тег для дополнительной классификации
- **Transaction** — операция (расход, доход, перевод, платёж по долгу)
- **Budget** — бюджет на категорию/актора/тег
- **Debt** — долг (кредит, кредитная карта, личный долг)
- **DebtPayment** — платёж по долгу
- **RecurringRule** — регулярный платёж/подписка
- **Goal** — финансовая цель

### Денежная модель
- Все суммы хранятся в **копейках** (integer, минорные единицы)
- Никаких float для денег
- Отображение: `Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' })`
- Пример: `123456` копеек → `1 234,56 ₽`

## 🔐 Безопасность

- Все данные хранятся **локально** в браузере (localStorage)
- Нет серверной части — нет утечек через API
- Рекомендуется регулярно делать бэкап (Настройки → Экспорт → JSON)
- Для продакшена рекомендуется подключить Supabase + RLS

## 📈 Метрики дашборда

| Метрика | Формула |
|---------|---------|
| Баланс | Σ текущих балансов активных личных счетов |
| Чистая стоимость | Активы − Обязательства |
| Доходы месяца | Σ операций type=income за текущий месяц |
| Расходы месяца | Σ операций type=expense (без переводов и тела кредита) |
| Дельта | Доходы − Расходы |
| Свободные деньги | Доход − Обязательные платежи − Платежи по долгам |
| Обязательная нагрузка | Обязательные платежи / Доход × 100% |
| Кредитная нагрузка | Ежемесячные платежи по долгам / Доход × 100% |

## 🎯 Стратегии погашения долгов

### Лавина
Сначала гасим долг с **максимальной ставкой** — минимизируем переплату по процентам.

### Снежный ком
Сначала гасим **самый маленький долг** — быстрее закрываем первые долги, мотивируемся.
