# 💰 Казна — Личный финансовый трекер

**Казна** — современное PWA-приложение для управления личными финансами в стиле Material Design 3. Бюджеты, долги, аналитика, импорт из Excel.

## ✨ Возможности

### Основной функционал
- **Обзор** — общая картина финансов с одного взгляда
- **Операции** — доходы, расходы, переводы, платежи по долгам
- **Счета** — дебетовые карты, кредитки, наличные, вклады, кошельки
- **Бюджеты** — лимиты по категориям с прогнозом превышения
- **Долги** — кредиты, кредитные карты, личные долги с симулятором погашения
- **Аналитика** — графики по категориям, акторам, месяцам, неделям
- **Цели** — накопления с прогрессом и дедлайнами
- **Настройки** — управление категориями, импорт/экспорт, тема

### Дизайн
- **Material Design 3** — как в свежем Android (Material You)
- **Шрифт Inter** — современный, хорошо читается
- **Тёмная и светлая тема**
- **Мобильный-first** с нижней навигацией
- **Сокращённые суммы** — 652 000 → 652К, 1 500 000 → 1.5М
- **Плавные анимации** и Material-тени

### Финансовая логика
- Переводы между своими счетами НЕ считаются расходами
- Оплата тела кредита НЕ считается обычным расходом
- Проценты и комиссии учитываются как финансовые расходы
- Амортизация крупных трат (годовые подписки = 1/12 в месяц)
- Расчёт свободных денег, обязательной и кредитной нагрузки
- Чистая стоимость = активы − обязательства

### Управление категориями
- Добавление новых категорий
- Редактирование названий
- Настройка иконок
- Все категории настраиваются пользователем

### Импорт и экспорт
- Импорт из Excel (.xlsx) с авто-нормализацией
- Экспорт в Excel, CSV и полный JSON-бэкап

### PWA
- Установка на смартфон
- Работа офлайн (localStorage)
- Material FAB для быстрого добавления

## 📱 Установка на телефон

**Казна — это PWA (Progressive Web App)**, а не APK. Она устанавливается прямо из браузера и работает как обычное приложение.

### На Android (Chrome, Edge, Samsung Internet)

1. **Откройте Казну в браузере Chrome**
2. **Дождитесь баннера «Установить Казну»** внизу экрана
   - Или нажмите меню браузера (⋮) → «Добавить на главный экран»
3. **Нажмите «Установить»** в появившемся окне
4. **Готово!** Иконка 💰 появится на главном экране

### На iPhone / iPad (Safari)

1. **Откройте Казну в Safari** (только Safari!)
2. **Нажмите кнопку «Поделиться»** (квадрат со стрелкой)
3. **Прокрутите вниз** → «На экран Домой»
4. **Нажмите «Добавить»**
5. **Готово!** Иконка 💰 появится на главном экране

### Подробная инструкция

В приложении есть страница **Настройки → Установить на телефон** с пошаговой инструкцией.

### FAQ

**Нужен ли APK?**
Нет. PWA устанавливается из браузера без APK.

**Работает ли офлайн?**
Да. Все данные хранятся локально на устройстве.

**Как удалить?**
Как обычное приложение: долгое нажатие на иконку → «Удалить».

## 📊 Модель данных

### Сущности
- **Account** — счёт (карта, наличные, вклад, кредитка, кошелёк)
- **Actor** — человек или организация
- **Category** — категория расходов (древовидная)
- **Transaction** — операция (расход, доход, перевод, платёж)
- **Budget** — бюджет на категорию
- **Debt** — долг (кредит, кредитная карта, личный долг)
- **RecurringRule** — регулярный платёж/подписка
- **Goal** — финансовая цель

### Денежная модель
- Все суммы в **копейках** (integer)
- Отображение: `Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' })`
- Сокращённый формат: 652К, 1.5М
